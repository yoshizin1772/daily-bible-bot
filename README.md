# 📖 Bot de Versículos Cristãos

Bot Discord feito em Node.js que envia versículos bíblicos automaticamente todos os dias.

## 🚀 Tecnologias
- Node.js
- Discord.js
- Puppeteer
- Node-cron

## 📂 Estrutura

src/
├── events/
├── services/
└── index.js

## ⚙️ Instalação

npm install

## ▶️ Iniciar

node src/index.js

## 🔐 .env

DISCORD_TOKEN=
CHANNEL_ID=

## 📌 Funcionalidades
- Versículo diário
- Embed automática
- Agendamento com cron
- Scraping bíblico

## 🧠 Conceitos usados
- Async/Await
- Puppeteer
- Eventos
- Organização backend
